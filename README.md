# API Testing — Yandex Lavka

## Project Description

Developed a checklist based on the Yandex Lavka API requirements and documentation, and tested new functionality using Postman, including product set management, delivery cost calculation, and shopping cart operations.

## Tools

- Postman
- API documentation
- Checklists

## Results

Tested 5 API endpoints covering product set management, delivery cost calculation, and shopping cart operations. The checklist helps verify API behavior against requirements and identify issues with product sets, delivery cost calculation, and shopping cart management before release.
